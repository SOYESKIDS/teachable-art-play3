## 구현

1. 교사 수업 로그인은 `/teacher` 오늘의 수업으로 진입한다. 원장은 `/learning`을 유지한다.
   소속·역할 확인, 기관 선택, 수업 날짜·계약·담당 반 제한은 기존 서버 흐름을 따른다.
   예정 수업을 자동 생성하거나 기존 3주차의 날짜/상태를 바꾸지 않는다.
2. 과정별 계약 범위 포함/일부 포함/범위 밖을 구분한다. 8주 계약의 16·24주 카드는
   전체 수업이 열린다고 오해하지 않게 '과정 구성 보기' 테두리 버튼으로 표시한다.
   읽기 전용 계약에는 시작을 약속하지 않는다. 발행 상태를 계약 포함으로 추정하지 않는다.
3. 수업 지도·주차 화면에서도 역할별 공통 업무 메뉴를 사용하고 기관 query를 보존한다.
4. STARTER 평문 교안의 준비 탭은 퀵 가이드→준비물→안전 순으로 먼저 표시한다.
   탭별 목차, 네이티브 펼치기/접기, 16px 본문을 추가했다. 저장 본문 문자열은 변경하지 않는다.
5. 교실 화면의 자료 미연결 설명은 아이 본문에서 교사 안내로 옮겼다.
   안내 버튼은 TV에도 보인다고 명시하고 장면 이동 시 닫는다. 별도 교사 기기 분리는 아직 아니다.
   영상/음원/그림책 재생기가 구현됐다고 표시하지 않으며, 보유 자료는 교사가 별도로 준비한다.
6. 홈페이지의 미술 5영역 및 도움 단계 도식을 제거했다. 실제 기록 기능은 유지하고
   관찰 기준 개편은 검수 후 안내한다고 표시한다. DB 분류·이전 기록·AI 프롬프트를 일괄 치환하지 않는다.
7. 본사 9주차 대조 화면에 촬영 안내 충돌을 추가로 알린다.
   저장소의 전사 참고 상태가 실제 DB 발행 판정처럼 보이던 문구도 수정했다.
