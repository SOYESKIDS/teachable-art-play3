   `resolve_organization_content_program(uuid)`로 교체했다. 계약표 RLS는 유지하며
   활성 소속/역할을 확인한 뒤 교안 ID 하나만 반환한다.
2. 빈 섹션은 성공한 빈 교안이 아니다. draft 서비스 요청은 본문/장면/출처를 조회하지 않는다.
   기존 STARTER 평문만 별도로 표시하고 실제 차시 ID의 회차에 연결했다.
   TAP24 손상/혼합 형식/0행/draft를 평문 보기나 fixture로 감추지 않는다.
3. 직접 소스 배포에 필요한 STARTER manifest를 포함했다. 실제 배포에서 발견한
   OG 폰트 ENOENT는 `outputFileTracingIncludes`로 수정했다.
   로그인/learning 서버 trace에 두 폰트 파일이 들어간 것도 확인했다.
4. 자료 목록 RPC는 SECURITY INVOKER인데 경로 SELECT 권한이 없는 상태로 경로 컬럼을
   직접 읽어 42501이 났다. 공개 함수는 invoker를 유지하고 private 함수가
   호출자/반/배정 교안/계약 범위를 확인한 뒤 파일 등록 여부만 반환한다.
   본사 권리 메모는 본사에게만 제공하며 원본 경로 SELECT 권한은 계속 거부한다.
   본사 목록에서도 같은 보호 컬럼 접근 문제를 고쳤다.
