## 8. 수정 계획

1. Hero: eyebrow 유지 · 설명을 "담임교사가 직접 운영하는 통합예술 수업과 수업 이후의 관찰 · 기록까지 하나의 흐름으로" · CTA = **도입 상담 신청**(primary) + **8주 프로그램 보기** + 작은 텍스트 링크 "20분 데모 · 4주 파일럿".
2. Header · 모바일 고정 CTA · Final CTA 를 도입 상담으로 (상담 폼 `consult` 유형 · data-cta 이름도 `consult-*`).
3. 순서: Hero → 문제 → 해결 흐름 → **콘텐츠 → 한 번의 수업** → 8주 여정 → 성장기록 → 역할 → 원장 화면 → 상품 → 도입 → 신뢰 → CTA.
4. 문제 섹션: 운영자 문장 4개 기준으로 다듬기 (교사 탓 · 공포 표현 없이).
5. 콘텐츠: 마음동화·EBOOK → VOD·음원 → 워크북 → 창의활동 키트 → 관찰 기록, 핵심 문장 "콘텐츠를 하나씩 제공하는 것이 아니라 …".
6. 한 번의 수업: **이야기 열기 → 몸으로 느끼기 → 나답게 표현하기 → 친구와 나누기 → 교사 관찰 기록**. 시간은 DEC-023 표준 골격을 묶어 표시(13 · 22 · 10 · 5분 + 워크북 별도 10분), 다섯 번째는 "수업 중 · 후".
7. 8주 여정: 제목 "씨앗에서 숲까지" · 묶음 = 시작 · 경험 · 표현(1~3주) → 함께 자람(4~7주) → 하나의 숲(8주).
8. 성장기록: 헤드라인 "잘했는지를 점수로 매기지 않습니다. 어떻게 참여했는지를 기록합니다." · 단계 4개(기록 없음 포함) · 기록 없음 정의.
9. 역할: 원장 = 반별 진행 · 미완료 업무 · 기록/리포트 상태 · 프로그램 운영 상태.
10. 상품: BEST 삭제 · 카드 = 한 문장 정의 → 추천 기관 → 기간 → 포함 → 남는 것 → 지금 포함되지 않는 것 → CTA.
11. 도입: 상담 → 운영 방식 확인 → 기관 · 반 설정 → 교사 온보딩 → 첫 수업 → 운영 확인 (6단계).
12. 신뢰: 첫 네 줄 = AI 는 진단하지 않음 · 점수 아님 · 비교 없음 · 교사 최종 확인.
13. `site-copy.ts` 미사용 export 삭제.
