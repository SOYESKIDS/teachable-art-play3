## 1. Teacher Daily Flow

```text
로그인 → 오늘의 수업
  → [수업 준비] → BEFORE (필수 확인)
  → [수업 시작] → DURING (6단계)
  → [수업 마치기] → 수업 종료
  → AFTER ① 출결 → AFTER ② 관찰 ([관찰 완료하고 다음 아이] 반복 → [관찰 마무리])
  → 리포트 · 주간 대기열 → 작성 → [리포트 완료]
```

## 2. Session State ↔ Action (DEC-098)

| 상태 | 화면 | 주 행동 | 없어야 하는 것 |
|---|---|---|---|
| scheduled | 오늘의 수업 카드 | **[수업 준비]** → BEFORE | 카드의 직접 시작 · "수업 완료" 버튼 |
| scheduled (BEFORE) | 준비 체크리스트 | **[수업 시작]** (필수 확인 완료 시만 활성) | 건너뛰기 |
| in_progress | DURING | 6단계 **[수업 마치기]** · 그 전에는 더보기 + 확인 1회 | — |
| completed | AFTER | [관찰 기록으로] | — |

- **scheduled → completed UX는 어디에도 없다** (Teacher · Director · HQ 모두).
- Director · HQ에게 일반 [수업 마치기] 없음. 예외는 §10 복구 처리.
- 표시 문구: 버튼 "수업 시작" · "수업 마치기" / 상태 "수업 종료" (DEC-034: 수업 종료 · 관찰 완료 · 리포트 완료를 같은 "완료"로 부르지 않는다).
- 취소는 현재 규칙 유지 (DEC-085).

## 3. Class Mode Layout

- **별도 immersive 전체 화면**이다. 메뉴 없음 · 상단 단계 바 + [나가기] · 하단 고정 action bar.
- 화면이 넓어져도 HQ/Desktop 고밀도 layout으로 바꾸지 않는다. tablet portrait · landscape · desktop 모두 큰 글자 · 큰 touch target(기본 권장 56px 수준, PHASE 07 확정) · 넉넉한 간격을 유지한다.
- 주 행동 버튼 위치는 모든 단계에서 하단 action bar의 같은 자리 (실수 방지).
- 스크롤 위치 · 현재 단계 같은 비민감 navigation state는 유지 가능.

## 4. BEFORE (DEC-036 · DEC-098)

modal이 아니라 **한 화면 체크리스트**다.

| 영역 | 내용 | 구분 |
|---|---|---|
| 오늘 주제 | Week · 차시명 · 핵심 메시지 · 예상 시간 | 정보 |
| 6단계 요약 | 단계명 · 권장 시간 | 정보 |
| 준비물 · 공간 | 체크 | **선택** (서버 audit 필수 아님) |
| 안전 확인 · 사진/개인정보 확인 | 체크 | **필수** (서버 기록) |
| 오늘 사진 공유 안 함 원아 | 목록 | 정보 |
| 콘텐츠 목록 | 텍스트 표시 · 재생 없음 (DEC-029) | 정보 |

- 필수 항목에는 "필수" 글자를 붙인다 (색만으로 표시하지 않음).
- 필수가 남아 있으면 **[수업 시작] 비활성 + "필수 확인 N개 남음"**.
- 건너뛸 수 있는 것처럼 보이지 않게 하되 공포 · 과도한 경고 UI는 쓰지 않는다.
- 사진 관련 고정 문구(원본): "사진 촬영·공유는 기관의 보호자 동의 및 개인정보 운영 기준을 따릅니다".
- 콘텐츠 미준비: "수업 내용이 아직 준비되지 않았습니다." (DEC-037)

## 5. DURING

| 위치 | 내용 |
|---|---|
| 상단 | 단계 n/6 · 단계명 · 권장 시간 |
| 본문 | 핵심 한 문장 · 교사 질문 3~4개 · (접힘) 활동 가이드 |
| 상시 | 상황 도움말 · **빠른 메모** |
| 하단 bar | ◀ 이전 · 다음 ▶ · 6단계 **[수업 마치기]** |

- 재생 UI 없음. 필요 시 "음원 ① — 이 단계에서 사용" 같은 텍스트 · resource availability label만 (DEC-029).
- 시간 종료는 안내만 한다.
- 재진입 카드: "진행 중 · n단계 · 이어서".

## 6. AFTER ① 출결

- 기존 `AttendanceEditor` 패턴 유지: 출석 · 결석 · 지각 · 조퇴 · "미기록 N명 출석 처리" · 하단 고정 [출결 저장].
- 저장 성공은 화면 내 상태 표시로 충분하다 (토스트 남발 금지).

## 7. AFTER ② 관찰 (DEC-099)

### 7-1. 아동별 카드

순서: 교사 관찰 → 아이의 말 → 관찰 포인트 → 사진.

| 버튼 | 의미 |
|---|---|
| **[관찰 완료하고 다음 아이]** (Primary) | 현재 아동 Observation을 **complete**하고 다음 아동으로 이동 |
| [임시저장] (Secondary) | draft 저장 |
| [나중에 작성] (Tertiary) | 현재 아동을 complete하지 않고 다음 아동으로 이동 · 기존 draft는 그대로 · 저장하지 않은 변경이 있으면 미저장 경고 |
| 이전 / 다음 | 이동 |

"저장"과 "완료"를 같은 말로 쓰지 않는다. 상태 표시: 작성 중 · **관찰 완료**. 진행 표시 예: "완료 9 / 출석 14".

### 7-2. [관찰 마무리]

- **일괄 complete 버튼이 아니다.** AFTER 관찰 흐름을 끝내고 Weekly 대기열로 이동한다.
- 미작성 아동이 있으면 확인: **"미작성 N명의 관찰은 작성 중으로 남습니다. 나중에 이어서 작성할 수 있습니다."**
- 결석 아동을 자동 complete하지 않는다.

### 7-3. 아이의 말

- 이름 "아이의 말" · 도움말 "아이가 실제로 한 말만 그대로 적어 주세요. 없으면 비워 두세요."
- 빈 값 허용. AI 추천 문장 · 예상 발화 · 자동 채움처럼 보이는 요소 없음. AI 결과가 이 칸을 채우는 경로 없음.

### 7-4. Observation complete ≠ AI 확정

Observation complete가 Report Evidence 후보다. AI 정리 확정 여부는 complete 조건이 아니며 같은 상태처럼 표시하지 않는다.

## 8. 관찰 포인트 (Growth5 · DEC-100)

### 8-1. 입력

- 섹션 이름 **"관찰 포인트"**. 5개: 표현 다양성 · 형태·공간 구성 · 창의적 시도 · 활동 참여·몰입 · 자기 설명·소통.
- 기본 = 미선택 = **기록 없음** (metric row 없음 · DEC-086). **"기록 없음" 버튼은 없다.**
- 지표를 선택했을 때만 Stage 3개를 보여준다. Stage를 고르지 않으면 저장할 수 없고 안내한다: "방식을 선택하거나 이 관찰 포인트 선택을 해제해 주세요."
- 5개 지표는 같은 크기 · 같은 중립색 · 번호 없음. 필수 선택 아님.

### 8-2. Metric Card

지표명 · 1줄 관찰 가이드(예: "제시된 방법과 다른 방식을 꺼내 본 모습") · 선택 상태 · Stage 선택. **별도 메모 칸 없음** (교사 관찰과 중복 작성 금지).

### 8-3. Stage

| 표시 | 설명 (도움말) |
|---|---|
| **함께** | 교사나 친구와 함께, 또는 도움 속에서 나타난 모습 |
| **보고 나서** | 예시나 다른 사람의 모습을 본 뒤 이어 해 본 모습 |
| **스스로** | 추가적인 도움이나 예시 없이 아이가 스스로 시도하거나 이어간 모습 |

- 3개는 순서 없는 같은 모양 선택지 · 선택된 것만 강조색 1개.
- 금지: 상하 단계 · 능력 수준 설명 · 1/2/3단계 · Low/Medium/High · 화살표 · 진행바 · 점수 색 · gauge · 순위 · 합계 · 반 평균.
- 저장 코드(`together` · `after_modeling` · `independent`)는 UI에 노출하지 않는다.
- 고정 안내(원본): "이 기록은 점수나 발달 수준이 아니라 이번 활동에서 관찰된 참여 방식을 기록합니다." / "기록 없음은 못했다는 의미가 아닙니다."

## 11. AI C1 — 문장 정리 (DEC-105)

| 항목 | 내용 |
|---|---|
| 버튼 | **AI로 문장 정리하기** |
| 구조 | **교사 원문** · **AI 제안** (읽기 전용) · **교사 확정 문장** (편집 가능). [제안 반영]은 확정 칸에만 반영 · 원문 overwrite 금지 |
| 요청 중 | 교사의 일반 작성 화면 전체를 잠그지 않는다 · AI trigger만 중복 실행 방지 · 표시 "문장을 정리하고 있어요" · 요청 취소는 P0 필수 아님 |
| 실패 | "AI 정리를 지금 사용할 수 없습니다. 작성한 내용은 그대로 있으며, 직접 작성해 계속 진행할 수 있습니다." + 별도 [다시 시도] |
| 근거 부족 | "기록된 근거가 부족해 이 부분은 작성하지 않았습니다. 직접 작성하거나 관찰 기록을 추가해 주세요." |
| 노출 조건 | `ai_assist` · Report Entitlement · Service Ready · (AR-8 미해결 시 Pilot AI OFF) — 조건 미충족 시 버튼 숨김 |
| Director | AI 초안 · 제안 비노출 |

AI 실패는 Observation · Report 작업을 막지 않는다. 금지 표현은 [copy-terminology.md §6](./copy-terminology.md).

## 12. Save · Conflict · Offline (DEC-099 · DEC-111 · DEC-098)

### 12-1. 저장

| 대상 | 방식 |
|---|---|
| 빠른 메모 | server autosave |
| Observation · Report draft | **explicit save** ([임시저장]) |
| Complete | Save와 **별도 action** |

- **P0에서 교사 관찰 · 아이의 말 · 관찰 포인트 · Report draft를 localStorage · IndexedDB 등 지속 client storage에 기본 저장하지 않는다.**
- P0 보호 장치: dirty 표시("저장하지 않은 변경이 있습니다") · 앱 내부 이동 시 미저장 경고 (브라우저 beforeunload에만 의존하지 않음) · 네트워크 실패 시 현재 화면 메모리에 입력 유지 · 재시도 · 복사 가능한 fallback.
- reload · 기기 변경 이후 복구는 약속하지 않는다. 장기 local 보존이 필요하면 별도 Privacy/Security Decision.

### 12-2. 동시 수정 충돌

- last-write-wins 금지.
- 문구: "다른 선생님이 먼저 내용을 변경했습니다. 최신 내용을 다시 불러와 확인해 주세요."
- [최신 내용 불러오기] + 현재 화면의 내 입력을 복사할 수 있게 유지 (지속 저장 아님). 비교 UI는 P1.

### 12-3. Offline (P0)

- 상단 비파괴 banner: **"인터넷 연결이 끊겼습니다. 연결되면 다시 시도해 주세요."**
- **수업 시작 · 수업 마치기 · Observation Complete · Report Complete** 같은 authoritative 서버 전환은 연결 복구 전 수행하지 않는다 (버튼 비활성 또는 실패 안내).
- 비민감 navigation state(현재 단계 · 스크롤)는 유지 가능. 민감 child text는 §12-1 규칙.
- 완전 offline sync는 P2 (AD-12 확장).
