## 발견과 변경

- 오늘 날짜는 10월 16일이고 남은 실제 시험 수업은 10월 15일 예정이므로 오늘 KPI 0은 오류가 아니다.
  다만 지난 회차를 찾기 어려워 실제 조회된 회차 중 진행 중→오늘 예정→지난 예정→일정 미정 순으로
  준비/이어서 링크를 강조했다. 미래·완료·취소·부모 비활성 예정은 추천하지 않는다.
  날짜/상태를 바꾸거나 회차를 생성하지 않으며 최종 권한 판정은 기존 목적지 서버/RPC를 따른다.
- 기존 `/teacher/weeks`는 `listWeeks()`의 저장소 TAP24 전사/검수 상태와 원문 권장 시간을 보여줬다.
  실제로 연결된 기존 STARTER 발행본과 달라 보이는 문제다. 프로그램 페이지와 `LearningWeekMap`을 공유하고
  기관 이용권을 읽어 범위 포함/범위 밖/확인 실패를 구분한다. 주제와 활동은 구성 안내이며 DB 본문이 아니다.
  계약 포함을 발행/자료 재생 가능으로 추정하지 않고, 전사본 상태를 DB 발행 상태처럼 표시하지 않는다.
- 교사 이력에 실제 회차의 준비/이어서/완료 결과 확인 링크를 추가했다. 원장 공용 카드에는 기본 적용하지 않는다.
  이력 목록에서 상태를 직접 바꾸는 버튼은 추가하지 않았다.
- 주간 리포트 화면에 선택 반·주차·프로그램 맥락과 관찰 확인/보충 링크를 추가했다.
  같은 배정 ID·주차에서 이미 조회한 진행 중/완료 회차 ID만 재사용한다. 주차 번호로 다른 프로그램의
  회차를 다시 찾지 않으며 신규 DB 질의도 추가하지 않았다. 관찰 없는 원아의 리포트 생성 규칙은 그대로다.
- 수정한 교사 홈/지도/이력/리포트 메뉴는 기관 query를 유지한다. 공통 교직원 화면에는 본문 건너뛰기를 추가했다.
  Vercel Preview는 `개발 검토`를 표시한다. 이 표시는 배포 종류이며 DB 대상 확인을 대신하지 않는다.
