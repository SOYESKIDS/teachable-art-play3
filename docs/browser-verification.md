# 브라우저 검증 목록

마지막 갱신: 2026-10-13 · 기준 커밋 `f5c0e9c`

이 목록은 **무엇을 어떤 방법으로 확인했는지**를 구분해 적는다. 자동 검사가 통과한 것을
사람이 화면에서 확인한 것으로 올려 적지 않는다.

## 검증 수준을 세 단계로 구분한다

| 수준 | 방법 | 확인되는 것 | 확인되지 않는 것 |
|---|---|---|---|
| **A. 코드 검사** | `tsc` · `eslint` · `node --test` · `next build` | 타입·규칙·순수 로직·빌드 성공 | 화면에 그려진 결과 |
| **B. HTTP·HTML·CSS 점검** | `next start` + `curl` + 빌드 산출물 검색 | 응답 코드, 리다이렉트, HTML 에 특정 문구·요소가 실렸는지, CSS 규칙이 번들에 들어갔는지 | 레이아웃, 실제 조작, 인쇄 결과 |
| **C. 사람이 브라우저에서** | 실제 클릭 · 키보드 · 기기 폭 · 인쇄 미리보기 | 보이는 배치, 조작 가능성, 종이 결과 | — |

**B 는 C 를 대신하지 않는다.** HTML 에 `@page size: A4` 가 실렸다는 것은 인쇄 결과가
한 장이라는 뜻이 아니다.

- `npm run lint` → 오류 0 · 경고 0

이전 커밋의 결과를 다음 커밋의 결과로 쓰지 않는다. 각 묶음마다 다시 돌린다.

## B. HTTP·HTML·CSS 점검 — 일부 확인

| 항목 | 방법 | 결과 |
|---|---|---|
| 공개 경로 응답 | `curl` → `/`, `/sample`, `/curriculum`, `/pricing` | 200 |
| 공개 샘플의 장면 이동 요소 | 응답 HTML 에서 「이전」·「다음」·「화면 쉬기」 문자열 확인 | 실렸음 |
| 공개 샘플의 출처 표시 | 「화면 설명 (수업 내용 아님)」 5곳 | 실렸음 |
| A4 인쇄 규칙 | `.next/server` 에서 `@page { size: A4; margin: 12mm; }` 검색 | 번들에 포함 |
| 업무 화면 링크 연결 | 42개 경로가 어딘가에서 참조되는지 검색 | 끊긴 경로 없음 |
| 보호 경로 접근 | `curl` → `/teacher/**`, `/director/**`, `/admin/**` | **확인 못 함** (아래) |

### 보호 경로를 점검하지 못한 이유

이 작업 트리에 Supabase 환경변수가 없어 보호 경로가 500 을 돌려준다
(서버 로그: `Supabase environment variables are missing.`). 환경변수를 만들거나 인증을
우회하지 않았다.

→ 환경변수가 있는 **Vercel Preview** 에서 테스트 계정으로 확인하는 것이 맞는 경로다.

## C. 사람이 브라우저에서 — 전부 검증 대기

도구 제약: 이 환경에 브라우저 자동화(Playwright 등)가 설치돼 있지 않다. 아래는 사람이
Preview 에서 확인해야 한다.

### 교실 화면 `/class/[sessionId]`

- [ ] 장면 이전·다음 이동 (버튼)
- [ ] 단축키 ← → (장면 이동)
- [ ] 단축키 F (전체화면) · B (뒤로) · T (교사 노트) · N (다음)
- [ ] 입력란에 포커스가 있을 때 단축키가 글자를 먹지 않는지
- [ ] 화면 쉬기 (가림막) 켜고 끄기
- [ ] 전체화면 상태가 실제 전체화면과 어긋나지 않는지
- [ ] 발표용 큰 화면(1920×1080)에서 글자 크기
- [ ] 장면 이동이 서버에 저장되지 않는다는 안내가 보이는지

### 주차 화면 `/teacher/weeks/[weekNo]`

- [ ] 탭 5개 이동 (준비 · 가이드 · 수업하기 · 관찰 · 결과보고)
- [ ] 탭을 옮겨도 선택한 기관·반이 유지되는지 (`?org=`, `?class=`)
- [ ] 회차 띠에서 「이 반으로 보기」가 반을 바꾸는지
- [ ] 회차가 없을 때 빈 상태 문구
- [ ] 회차 조회 실패 시 「불러오지 못했습니다」가 0건으로 보이지 않는지
- [ ] 발행 전 주차에서 본문이 열리지 않고 이유가 보이는지
- [ ] 360px 폭에서 탭과 회차 띠 배치

### 퀵 가이드 인쇄 `/teacher/weeks/[weekNo]/quick-guide`

- [ ] **A4 인쇄 미리보기에서 표 오른쪽이 잘리지 않는지**
- [ ] 머리말·버튼이 종이에 남지 않는지 (`print:hidden`)
- [ ] 표 한 행이 두 장에 걸쳐 끊기지 않는지
- [ ] 흑백 레이저에서 글자가 묻히지 않는지
- [ ] 준비물이 많은 주차에서 **몇 장이 나오는지** (2주차: 준비물 6행 + 안전 4행 + 진행 표 7행)
- [ ] 「준비물 면 덜어내기」로 한 장이 되는지
- [ ] 미발행 주차에서 인쇄본이 나가지 않는지

### 결과 보고 `/teacher/sessions/[sessionId]/report`

- [ ] 1~3단계가 실제 저장된 값을 보여 주는지
- [ ] 출결 미입력과 0명 참석이 다르게 보이는지
- [ ] 4단계에 입력란과 제출 버튼이 없고 그 이유가 보이는지
- [ ] 담당이 아닌 회차에서 404

### 원장 `/director/reports`

- [ ] 반별 주차 띠가 반마다 따로 보이는지
- [ ] 진행률(%)이 어디에도 없는지
- [ ] 회차별 결과보고서 저장 경로가 없다는 안내가 보이는지
- [ ] 성장 이야기(원아별)와 결과보고(반별)가 섞이지 않는지

### 본사 검수 `/admin/curriculum/weeks`

- [ ] 24주 목록에서 전사·검수·자료가 각각 보이는지
- [ ] 「없는 프로그램 N개」가 합계와 함께 보이는지
- [ ] 주차 상세에서 프로그램·차시별 내역이 합계와 나란히 보이는지
- [ ] 「전사 중 분명하지 않았던 곳」 목록이 보이는지
- [ ] 해시가 교사·원장 화면에는 나오지 않는지
- [ ] 전사 전 주차에서 발행 불가 사유가 보이는지
- [ ] 로그인하지 않은 접근이 막히는지

### 공개 페이지

- [ ] `/sample` 장면 이동과 단축키
- [ ] `/curriculum` 9주차 이후 안내 (`AVAILABLE_THROUGH_WEEK = 8`)
- [ ] `/pricing` 금액이 상품소개서와 같은지
- [ ] 360px 폭 배치
