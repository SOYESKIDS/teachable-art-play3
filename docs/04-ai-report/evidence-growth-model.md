## 1. Evidence Model (DEC-064)

Evidence의 기본 단위는 **관찰 1건 (세션 × 아동)**이며, 그 안의 노트 · 아이의 말 · Growth 5 선택 · 사진 참조를 하위 항목으로 둔다. DB 구조는 PHASE 05.

| Evidence | SOURCE | AUTHOR | SCOPE | TYPE | REFERENCE | AI 사용 | Parent 노출 |
|---|---|---|---|---|---|---|---|
| **Teacher Observation Note** | 관찰 기록 | 교사 | 세션 × 아동 | text | 관찰 ref | ✅ | 원문 그대로는 아님 → Teacher Final을 통해서만 |
| **Child Quote** | 관찰 `child_voice` | 교사 입력 (아이가 한 말) | 세션 × 아동 | **verbatim** text | 관찰 ref | ✅ **원문 그대로만** | ✅ 교사가 선택한 것 · 원문 그대로 |
| **Child Choice** | 관찰 노트에 기록된 구체적 선택 | 교사 | 세션 × 아동 | text | 관찰 ref | ✅ | ✅ 교사 선택 |
| **Growth 5 Selection** | 관찰 | 교사 | 세션 × 아동 × 지표 | 지표 + Stage | 관찰 ref · 지표 | ✅ 구조 그대로 | ◐ 서술로만 (§7) |
| **Selected Media** | 사진 | 교사 선택 | 세션 × 아동 | 사진 참조 | media ref | **✖** | ✅ consent-eligible만 |
| **Artwork / Workbook 존재** | 커리큘럼 take_home + 교사 확인 | 시스템 + 교사 | 세션 | 사실 | lesson · 세션 | ✅ 이름만 | ✅ |
| Attendance | 출결 | 교사 · 원장 | 세션 × 아동 | 상태 | 출결 ref | ✖ (근거 선택 필터로만) | **✖** |
| Quick Memo | 수업 중 메모 | 교사 | 세션 | text | — | **✖** | **✖** |

**Curriculum Context** (Evidence 아님): 주차 · 주제 · 성장키워드 · 그림책 · 활동 · 활동 목표 · 가정연계 · 다음 주 — 발행된 커리큘럼 버전.

## 2. Teacher Evidence vs Curriculum Context

| | Teacher Evidence | Curriculum Context |
|---|---|---|
| 무엇 | 이 아이에게 이번 활동에서 **관찰된 사실** | 모든 아이에게 같은 **수업 설계** |
| 예 | "붓 대신 손가락으로 찍었다" | "이번 주 핵심활동: 손도장 찍기" |
| 리포트 사용 | 아이에 대한 서술의 유일한 근거 | 주제 · 맥락 · 가정연계 · 예고 |
| 금지 | — | **목표를 결과로 옮기기** ("아이가 목표를 달성했다") · 커리큘럼 문구를 관찰처럼 쓰기 |

**Goal ≠ Observed Outcome.**

## 3. Official Growth 5 (DEC-005 · DEC-065)

| 지표 | 의미 | 교사가 기록하는 경우 | 기록하면 안 되는 것 | Evidence 예 | Parent 표현 범위 | Monthly · Semester |
|---|---|---|---|---|---|---|
| **1 표현 다양성** | 색 · 재료 · 방법을 **여러 갈래로 시도한 모습** (많을수록 좋다는 뜻 아님) | 새 재료를 써 봄 · 색을 섞어 봄 · 방법을 바꿔 봄 | "색감이 좋다" · 사용한 색 개수 · 작품의 질 | "빨강과 파랑을 섞어 보라색을 만들었다" | 활동 속 구체 행동 | 기간 중 관찰된 사례 |
| **2 형태·공간 구성** | 형태를 배치하고 공간을 다룬 모습 | 겹치기 · 위아래 배치 · 여백 · 입체로 쌓기 | "구도가 뛰어나다" · 정확도 | "블록을 3층으로 쌓고 문을 만들었다" | 구체 행동 | 사례 |
| **3 창의적 시도** | 제시된 방법과 **다른 방식**을 꺼내 본 모습 | 도구를 다르게 씀 · 규칙을 바꿔 봄 | "창의적인 아이" (성격 단정) | "붓 대신 손가락으로 찍었다" | 시도한 행동 | 사례 |
| **4 활동 참여·몰입** | 활동에 **머문 방식** (시간 길이 아님) | 반복 시도 · 다시 돌아옴 · 끝까지 머묾 | 집중력 수준 · "산만하다" | "탑이 무너지자 다시 쌓았다" | 머문 장면 | 사례 |
| **5 자기 설명·소통** | 자기 선택을 말 · 몸짓으로 전함 | 이유를 말함 · 작품 소개 · 가리키기 | 언어 능력 평가 · 발음 | "노란색이 기분 좋은 색이라서" | 아이의 말 원문 중심 | 대표 인용 |

모든 지표는 **이번 활동에서 관찰된 사실**만 기록한다. 아이의 일반 특성 · 능력을 기록하지 않는다. 허용 Stage는 모든 지표에서 동일하다 (§4).

## 4. Stage Semantics (DEC-007 · DEC-008 · DEC-038 · DEC-065)

| Stage | 의미 | 아닌 것 |
|---|---|---|
| **기록 없음** (기본 상태 · UI에서 누르지 않음) | 이번 활동에서 그 지표의 모습이 기록되지 않았다 | 못했다 · 부족하다 |
| **함께** | 교사 · 친구가 함께하거나 직접 도와주는 가운데 나타남 | 낮은 단계 · 도움이 필요한 아이 |
| **보고 나서** | 교사 · 친구의 모습을 본 뒤 나타남 | 중간 단계 |
| **스스로** | 먼저 시작해서 나타남 | 잘함 · 목표 · 최고 단계 |

| 규칙 | 내용 |
|---|---|
| S-1 | Stage는 **이 활동의 이 지표**에만 해당한다. 다른 활동 · 지표 · 아이로 옮기지 않는다 |
| S-2 | **0/1/2 변환 · 평균 · 합계 · 백분율 · 등급 · 반 평균 · 순위 금지** — 모든 계층 |
| S-3 | 순서 표현(→) · 진행바 · 색 그라데이션 금지 |
| S-4 | 교사가 지표를 "관찰했다"고 선택한 뒤 명시 선택지는 3개(함께 · 보고 나서 · 스스로). 미선택 = 기록 없음 (DEC-038) |
| S-5 | absent vs explicit NOT_OBSERVED 저장 방식은 PHASE 05 (IA-3) |
| S-6 | AI는 지표 · Stage를 선택 · 추천 · 검증하지 않는다. AI Stage 추천은 BASE PRODUCT 제외 (DEC-075) |

## 5. Growth Trend Rules (DEC-065)

| 허용 | 금지 |
|---|---|
| **같은 아이의 시간순 사례 목록** (주차 · 활동 · 지표 · Stage · 근거) | 반 평균 · 또래 평균 · 상위 N% · 또래 대비 · 백분위 · 순위 · 성취 점수 · 발달 수준 · 정상/지연 |
| 교사가 반복 관찰한 행동의 **기술적 요약** ("여러 차례 색을 섞어 보는 모습이 기록되었습니다") | "스스로가 늘었으므로 발달했다" 같은 인과 · 발달 판정 |
| 교사용 화면의 아이별 Stage 기록 **나열** | Stage 개수 집계 · 비율 · 그래프 · 레이더차트 |

**Parent용 안전 문장 규칙**: 주어는 "이번 기간의 기록" · 동사는 "기록되었어요 / 보였어요" · 기간과 활동 명시 · 비교 · 변화량 · 원인 서술 금지.
- ✅ "3~4주차 활동에서 재료를 섞어 보는 모습이 여러 번 기록되었어요."
- ✖ "색 표현이 크게 좋아졌어요."

## 6. Quick Memo (DEC-035 · DEC-064)

| 항목 | 정책 |
|---|---|
| 지위 | **Report Evidence가 아니다** |
| 자동 흐름 | Observation 자동 전환 · Report 유입 · AI 입력 **모두 금지** |
| Evidence가 되는 경우 | 교사가 **직접 옮긴** 경우에만 Teacher Observation Note가 된다 (메모 자체는 그대로 남음) |
| P0 | AFTER 화면에서 참고 · 수동 복사 |
| P1 | "관찰로 옮기기" 기능 후보 |
| 노출 | 교사 본인 · 담당 반 · Director · Parent 비노출 |

## 7. Child Quote Policy (DEC-064)

| 규칙 |
|---|
| Quote는 teacher-entered evidence **원문 그대로** 보존한다 |
| AI는 Quote를 새로 만들기 · 자연스럽게 고치기 · 문법 교정 · 내용 변경 · 두 문장 합치기를 **하지 않는다** |
| Teacher Final도 인용 원문을 바꾸지 않는다. 표시할 인용은 **Evidence ref에서 원문을 가져온다** |
| Parent 직접 노출 Quote(교사 선택)와 AI가 서술 작성 시 참고하는 Quote를 구분할 수 있다. AI가 인용할 때는 원문 그대로만 |
| 근거가 없으면 "아이의 말과 선택"은 비워 둔다. 시스템 · AI가 채우지 않는다 (DEC-066) |

## 8. Photo Boundary (DEC-014 · DEC-059 · DEC-064 · DEC-073)

| 규칙 |
|---|
| 사진은 **Display Asset**이며 **AI Evidence가 아니다**. AI 입력 · 얼굴 · 표정 · 사진 기반 심리 추론 금지 |
| 교사가 **consent-eligible** 사진만 선택한다. 사진 없이도 리포트 완료 가능 |
| 완료 Snapshot에는 사진 **참조**만 저장한다. **Immutable content snapshot ≠ 영구 photo visibility** — 학부모 노출은 현재 consent · privacy 정책으로 동적으로 차단될 수 있다 |
| Consent withdrawal: 사진 표시 차단. 텍스트 리포트 전체 삭제 · 재생성 · 과거 Snapshot 재작성을 **자동으로 하지 않는다** |
| 사진 테이블에 `observation_id`가 없으므로(CURRENT) 선택은 세션 × 아동 범위에서 한다 |
| 법적 처리 (단체 사진 · 동의 단위 · 삭제) | CO-9 · CO-10 · CO-2 |
