# 직원 UAT 피드백 분류 절차 (PHASE 10A)

새 SaaS 피드백 기능은 만들지 않는다. 수집은 `docs/10-employee-uat/feedback-template.md` 양식 + 담당자가 정한 문서 · 시트.

## 우선순위

| 등급 | 기준 | 예 | 대응 |
|---|---|---|---|
| **P0** | 서비스 불가 · 보안 · 데이터 노출 | 로그인 전체 불가 · 500 · **권한 밖 정보 노출**(Sales 에서 아동 이름 · 관찰) · 비밀 노출 | 즉시 담당자 · 당일 조사 · 필요 시 UAT 일시 중지 |
| **P1** | 핵심 역할 흐름 중단 | 교사 출결 · 관찰 · Weekly 저장 불가 · 원장 이력 · 공유 화면 오류 | 다음 수정 phase 최우선 |
| **P2** | 기능 오류 | 일부 버튼 · 목록 · 정렬 · 필터 오류 | 수정 phase 계획 |
| **P3** | UI · 문구 · 반응형 개선 | 오탈자 · 배치 · 모바일 레이아웃 | 묶어서 처리 |

양식의 긴급도와 대응: 서비스 중단 → P0 · 주요 기능 문제 → P1 (권한 노출은 P0) · 일반 오류 → P2 · UI/문구 개선 → P3.

## 상태

`new` → `confirmed`(재현 · 등급 확정) → `fixing` → `ready-for-retest`(수정 배포 · Preview Ready) → `closed`(제보자 또는 담당자 재확인)
분기: `deferred`(이번 범위 밖 · 사유와 연결 ID 기록 · 예: CO-12 · G-1 관련) · `confirmed` 에서 재현 불가면 `closed`(사유 "재현 불가").

## 저장소 기록 위치 (개인정보 · 민감정보 없이)

- `docs/10-employee-uat/feedback-log.md` (필요 시 생성) — **한 줄 요약만**: `UAT-### | 등급 | 상태 | 역할 | 페이지 | 요약(개인정보 없음) | 연결 ID | 수정 커밋`
- 넣지 않는 것: 제보자 실명 · 연락처 · 비밀번호 · 스크린샷 원본 · 아동 · 학부모 정보(합성이라도 스크린샷 금지) · Shareable Link · 계정 비밀번호
- 스크린샷 · 원문은 담당자 문서 · 시트에만 (저장소 밖)
- P0 보안 제보는 요약도 수정 후에 기록 (재현 방법은 수정 전 저장소에 쓰지 않는다)
