## 콘텐츠 기준

제공 이미지에 포함된 일부 책 제목·음원명은 현재 공식 교안과 다르다.
따라서 실제 4주차 발행 자료로 단정하지 않고 콘텐츠 **구성 예시**로 표시했다.
상품 가격·자료 제공 상태·재생 가능 여부는 기존 상품 데이터와 안내를 유지한다.
제공 이미지에 실사용 기관·성과를 확인할 근거가 없으므로 「실제 수업 현장」
표시 대신 「수업 장면 예시」를 사용한다.

## 검증

빌드·타입·린트·기존 테스트와 정적 홈페이지 HTML의 이미지 참조를 확인한다.
브라우저에서의 모바일 배치·실제 이미지 로딩은 Preview에서 추가 확인 대상이다.
